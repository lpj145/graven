# zidl Runtime + Benchmarks (Phases 1 and 2) Implementation Plan

> **Historical document.** Written on 2026-11-12, when the project was called zidl (later
> Graven). It is the plan that built the first runtime and the benchmarks against FlatBuffers
> and Cap'n Proto. Paths, names and some APIs changed afterwards; the normative text is the
> [format specification](../../spec/graven-format-v1.md).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust runtime for the zidl format (zero-copy reads, forward writing with a pool of
`BytesMut`), hand-written "generated" code for 4 scenarios, evolution tests, and benchmarks
against FlatBuffers and Cap'n Proto.

**Architecture:** A Cargo workspace with `zidl` (runtime), `zidl-layout` (the layout
algorithm, reused by the compiler in phase 3), `zidl-schemas` (the code the compiler would
generate, written by hand) and `zidl-bench` (criterion + flatbuffers + capnp). The format is
validated by benchmark before investing in the compiler.

**Tech Stack:** Rust 2024 (rustc 1.94), `bytes`, `proptest`, `criterion`, `flatbuffers`,
`capnp`/`capnpc`. External tools: `capnp` 1.5 (installed), `flatc` (**not installed** —
`sudo pacman -S flatbuffers`; the generated code is committed, so only whoever regenerates it
needs it).

**Spec:** `design/2026-11-12-zerocopy-idl-design.md`

## Global Constraints

- Little-endian everywhere; **no alignment padding**; reads via `from_le_bytes` over slices.
- Table = `[u16 fixed_len][fixed part]`. Slot offsets are relative to the **start of the
  fixed part** (the byte after the `u16`).
- Pointer = `i32` LE, relative to the **absolute position of the slot itself**
  (`target - slot_pos`); `0` = absent; may be negative.
- `string`/`bytes` = `[u32 len][bytes]`; `[scalar|struct]` = `[u32 count][elements]`;
  `[table]` = `[u32 count][u16 elem_fixed_len][count × fixed part]` (elements without a header
  of their own); `[string]`/`[bytes]` = `[u32 count][count × i32]`.
- Union slot = `[u16 tag][i32 offset]` (6 bytes); `tag 0` = absent; variants are tables only.
- Every scalar field (including enums and inline structs) has 1 presence bit; `bool` has 2
  bits in the **same byte** (presence = bit `k`, value = bit `k+1`). **1 = present.** A new
  fixed part = all zeros.
- Read rule: slot (or bit byte) outside `fixed_len` ⇒ absent; slot partially inside ⇒
  `Err(Truncated)`; otherwise the bit/offset/tag decides.
- Reading a malformed buffer: **never a panic, never UB** — always `Err`. No `unsafe` in the
  runtime, except `str_unchecked`, explicitly an `unsafe fn`.
- Hot write path with a warm pool: **zero allocations per message**.
- `zidl` builds with `--no-default-features` (`no_std + alloc`); the `std` feature (default)
  enables `SimplePool`.
- Message ≤ `i32::MAX` bytes; exceeding it ⇒ `Err(TooLarge)` on write (not a panic).
- `verify` defaults: `max_depth = 64`, budget of bytes visited = `max(buf.len() * 8, 1 MiB)`.

## Review Focus

1. Random/truncated bytes / an offset pointing outside or before 0 / `len = u32::MAX` → `Err`,
   never a panic (proptest in Task 5; fixed cases in Task 2).
2. An abandoned streaming list (drop without `close`, or `?` exiting halfway) and a `Builder`
   dropped without `finish` → no panic, buffers return to the pool (Tasks 3 and 4).
3. `Bytes` of a previous message still alive while the same pool builds the next one → the
   old message stays intact (Task 3).
4. An empty string present vs absent; an empty list present vs absent → distinguishable
   (Task 3).
5. A streaming list element with a string + a nested table + a nested streaming list →
   correct offsets after the fix-up (Task 4).

### Task 3: Pool, `Builder` and `TableW` (without table lists)

**Files:** Create `crates/zidl/src/pool.rs`, `crates/zidl/src/write.rs`

**Interfaces:**
- Consumes: `Le`, `Bit`, `Error`; `TableRef` only in the tests.
- Produces:
  - `pub trait BufPool { fn take(&self) -> BytesMut; fn give(&self, b: BytesMut); }`
  - `#[cfg(feature="std")] pub struct SimplePool` — `SimplePool::new(initial_capacity: usize)`; `take` reuses (`clear()` + `reserve`) or creates; `give` stores.
  - `pub struct Builder<'p> { pool: &'p dyn BufPool, buf: BytesMut }`
    - `Builder::new(pool: &'p dyn BufPool) -> Self`
    - `fn root(&mut self, fixed_len: u16) -> TableW<'_>` — writes the header + `fixed_len` zeros at `0`.
    - `fn finish(mut self) -> Result<Bytes, Error>` — `buf.split().freeze()`, returns the rest of the `BytesMut` to the pool (the space is reclaimed by `reserve` when the `Bytes` dies); `Err(TooLarge)` if `len > i32::MAX`.
    - `impl Drop` — if not finished, returns `buf` to the pool.
  - `pub struct TableW<'b>` (internals free; it must write the fixed part into a "fixed" buffer that can be the main one or the auxiliary buffer of a streaming list, and variable-size data always into the main one). Methods:
    - `fn set<T: Le>(&mut self, off: u16, presence: Bit, v: T)`
    - `fn set_bool(&mut self, presence: Bit, v: bool)`
    - `fn set_str(&mut self, off: u16, s: &str)`, `fn set_bytes(&mut self, off: u16, b: &[u8])`
    - `fn set_scalars<T: Le>(&mut self, off: u16, v: &[T])`
    - `fn set_strs<'s>(&mut self, off: u16, v: impl ExactSizeIterator<Item = &'s str>)`
    - `fn table(&mut self, off: u16, fixed_len: u16) -> TableW<'_>` — a child in the main buffer.
    - `fn union(&mut self, off: u16, tag: u16, fixed_len: u16) -> TableW<'_>`
  - Writing a pointer: value = `target_pos - slot_pos`, where `slot_pos` is the position of the slot **in the buffer that holds the fixed part** (in the auxiliary buffer, it is the index in the auxiliary buffer — corrected by the fix-up in Task 4).

### Task 4: Table lists (known count and streaming) with fix-up

**Files:** Modify `crates/zidl/src/write.rs`

**Interfaces:**
- Consumes: `TableW`, `BufPool` (Task 3)
- Produces (methods of `TableW<'b>`):
  - `fn tables(&mut self, off: u16, n: u32, elem_fixed_len: u16) -> TableListW<'_>` — reserves the header + `n` zeroed fixed parts in the main buffer. `TableListW::push(&mut self) -> TableW<'_>` (a programming panic if it exceeds `n` is acceptable: that is a writer bug, not external data). On `Drop`: corrects `count` to the real one (the rest becomes dead bytes).
  - `fn tables_streaming(&mut self, off: u16, elem_fixed_len: u16, ptr_slots: &'static [u16]) -> StreamListW<'_>` — `ptr_slots` = the offsets (in the fixed part) of every `i32` pointer of the element, including `union_off + 2`. Takes an auxiliary buffer from the pool. `StreamListW::push(&mut self) -> TableW<'_>` (fixed part in the auxiliary buffer). `close(self)` and `Drop` do:
    1. append `[u32 count][u16 elem_fixed_len]` to the main buffer; `B` = the next position;
    2. `extend_from_slice(aux)` (one memcpy);
    3. for each element and each `ptr_slot` with a value ≠ 0: `value -= B` (in `i64`, checked);
    4. patch the parent's slot; `aux.clear()` and `pool.give(aux)`.
  - `fn scalars_streaming<T: Le>(&mut self, off: u16) -> ScalarListW<'_, T>` — appended directly to the main buffer; `push(v: T)`; `Drop` corrects `count`. It **cannot** coexist with another open variable-size datum (guaranteed by `&mut`).

### Task 6: `zidl-layout` — the layout algorithm

**Files:** Create `crates/zidl-layout/{Cargo.toml,src/lib.rs}`

**Interfaces:**
- Produces:
  - `pub enum FieldKind { Scalar { size: u16 }, Bool, Ptr, Union }` (inline enum/struct = `Scalar` with its size; `Ptr` = string/bytes/list/table, 4 bytes; `Union` = 6 bytes)
  - `pub struct FieldLayout { pub slot: Option<u16>, pub presence: Option<(u16, u8)> }` (`(byte, shift)`)
  - `pub struct TableLayout { pub fixed_len: u16, pub fields: Vec<FieldLayout> }`
  - `pub fn compute_layout(fields: &[FieldKind]) -> TableLayout` — `fields` in ID order, **including** the `reserved` ones with their original type.
- Algorithm (fixes spec §4.3):

```
cursor = 0; open = None  // (byte_pos, next_shift)
for f in fields:
  need = match f { Scalar => 1, Bool => 2, Ptr | Union => 0 }
  if need > 0:
    if open is Some((p, s)) and s + need <= 8: presence = (p, s); open = (p, s+need)
    else: presence = (cursor, 0); open = (cursor, need); cursor += 1
  if f is not Bool: slot = cursor; cursor += size(f)
fixed_len = cursor
```

**Schemas** (syntax of spec §6; IDs in order):
```

enum Currency : u16 { BRL = 0, USD = 1, EUR = 2 }
table Entry { account @0: u64; amount @1: i64; memo @2: string?; }
table Transaction { id @0: u64; ts @1: u64; currency @2: Currency; from_shard @3: u32;
                    to_shard @4: u32; entries @5: [Entry]; note @6: string?; }
// game.zidl
struct Vec3 { x: f32, y: f32, z: f32 }
table Entity { id @0: u32; pos @1: Vec3; vel @2: Vec3; hp @3: u16; alive @4: bool; }
table Frame { tick @0: u64; entities @1: [Entity]; }
// iot.zidl
table Telemetry { device @0: u32; ts @1: u64; temp @2: f32; humidity @3: f32?; battery @4: u8; }
// stream.zidl
table Chunk { stream_id @0: u64; seq @1: u32; data @2: bytes; }
```

**Interfaces (the pattern the phase 3 compiler will reproduce — fixed here):**
- Per table `X`: a module with `pub const FIXED_LEN: u16`, a slot/`Bit` `const` per field, `pub(crate) const PTR_SLOTS: &[u16]`.
- `pub struct X<'a>(TableRef<'a>)`:
  - `X::read(buf: &'a [u8]) -> Result<Self, Error>` (root at 0) and `X::from_ref(t: TableRef<'a>) -> Result<Self, Error>` — both validate required fields ⇒ `Err(Missing { field: "name" })`.
