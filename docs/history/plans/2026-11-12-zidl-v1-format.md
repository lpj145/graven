# zidl v1 — Format: envelope, Verified, spec and vectors (Plan 1 of 3)

> **Historical document.** Written on 2026-11-12, when the project was called zidl (later
> Graven). It is the plan that froze format v1. Names and some details changed afterwards
> (for example, the magic became `GRVN` and namespaces no longer carry versions); the
> normative text is the [format specification](../../spec/graven-format-v1.md).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze format v1: new errors, CRC32C, the `to_bytes`/`from_bytes` envelope (with and
without the `Builder`), an API without public `unsafe` (verified views), a normative spec and
conformance vectors generated by a dynamic reader/writer independent of the generated code.

**Architecture:** Everything about the envelope and the CRC lives in the `zidl` runtime
(`no_std + alloc`). The verified views are written by hand in `zidl-schemas` following the
same pattern the compiler (Plan 2) will generate. Conformance lives in a new crate
`zidl-conformance` with a **dynamic interpreter** (a schema described as data → read/write via
`TableRef`/`TableW` + `zidl-layout`) that generates and checks the frozen vectors; Plan 2
checks the generated code against the same vectors.

**Tech Stack:** Rust 2024, `bytes`, `crc32c` 0.6.9 (only with the `std` feature), `proptest`,
`serde` + `serde_json` (only in the conformance crate), criterion.

**Spec:** `design/2026-11-12-zidl-v1-hardening-design.md` (parts A, B, C and the review items
of part E). Following plans: 2 = compiler + lockfile (part D); 3 = fuzzing, generated matrix,
Miri, report (part E).

## Global Constraints

- No git: **do not** create commits or branches (the user's preference). Where the template
  asks for a commit, the step is to run `cargo test --workspace` and move on.
- The wire format of the raw message does NOT change. The envelope is an addition.
- The `zidl` runtime keeps building with `--no-default-features` (`no_std + alloc`).
- Performance: writing/reading **without an envelope** within ±5% of
  `benchmarks/2026-11-12-round2.md`.
- No panic and no UB when reading malformed bytes, including the envelope.
- No `unsafe` function reachable by safe code outside `#[doc(hidden)]`.
- Envelope header = 20 bytes, a 4-byte CRC32C at the end, little-endian, magic `"ZIDL"`,
  `format_version = 1`.

## Review Focus

1. `payload_len = u32::MAX` (or any value that overflows `20 + N + 4` on 32 bits) ⇒
   `Incomplete`, never a panic/overflow. → Task 3, `decode_huge_len_is_incomplete`.
2. Several concatenated envelopes with a corrupt one in the middle ⇒ the iterator stops with
   `ChecksumMismatch` and does not silently "resynchronize". → Task 4,
   `envelopes_stop_at_corruption`.
3. `from_bytes` with an intact envelope of another root type ⇒ `SchemaMismatch` before looking
   at the payload. → Task 5, `from_bytes_wrong_schema`.
4. A verified view built from unverified bytes by safe code ⇒ does not compile. → Task 5,
   `compile_fail` doctest.
5. An envelope with an empty payload (`payload_len = 0`) ⇒ `decode` accepts it, `from_bytes`
   returns `OutOfBounds` from reading the root, no panic. → Task 3, `decode_empty_payload`.

### Task 3: Envelope `encode` / `decode`

**Files:**
- Create: `crates/zidl/src/envelope.rs`
- Test: `crates/zidl/tests/envelope.rs`

**Interfaces:**
- Consumes: `crc32c`, the errors from Task 1.
- Produces:
  ```rust
  pub const MAGIC: [u8; 4] = *b"ZIDL";
  pub const FORMAT_VERSION: u8 = 1;
  pub const HEADER_LEN: usize = 20;
  pub const TRAILER_LEN: usize = 4;
  pub const fn schema_id(qualified_name: &str) -> u64; // FNV-1a 64: offset 0xcbf29ce484222325, prime 0x100000001b3
  pub fn encode(schema_id: u64, payload: &[u8], out: &mut BytesMut) -> Result<(), Error>; // TooLarge if payload > i32::MAX
  pub fn decode(buf: &[u8]) -> Result<Envelope<'_>, Error>;
  #[derive(Debug, Clone, Copy, PartialEq, Eq)]
  pub struct Envelope<'a> { pub schema_id: u64, pub payload: &'a [u8], len: usize }
  impl Envelope<'_> { pub fn len(&self) -> usize /* bytes consumed = 24 + payload */ }
  ```
  Layout and check order: exactly §B of the design (`Incomplete` for a short header → magic → version → flags≠0 or reserved≠0 ⇒ `BadHeader` → `payload_len` fits ⇒ otherwise `Incomplete { needed }` → CRC over `[0, 20+N)`). `needed` computed in `u64`/`checked_add`; if it does not fit in `usize`, `needed = usize::MAX`.

  - `roundtrip`: decode(enc(7, b"hello")) → `schema_id 7`, payload `b"hello"`, `len() == 29`.

### Task 4: Copy-free envelope in the `Builder` and iteration

**Files:**
- Modify: `crates/zidl/src/write.rs` (`Builder`, `begin_msg`), `crates/zidl/src/envelope.rs` (`envelopes()`)

**Interfaces:**
- Produces:
  ```rust
  impl<'p> Builder<'p> {
      pub fn new_enveloped(pool: &'p dyn BufPool) -> Self; // reserves HEADER_LEN before each message (instead of 4)
      pub fn flush_envelope(&mut self, schema_id: u64) -> Result<Bytes, Error>; // header + payload + crc, without copying the payload
      pub fn seal_envelope(&mut self, schema_id: u64) -> Result<(), Error>;     // batch = concatenated envelopes
  }
  pub fn envelopes(buf: &[u8]) -> Envelopes<'_>; // Iterator<Item = Result<Envelope<'_>, Error>>; stops at the first Err
  ```
  Rules: the `Builder` keeps `prefix: usize` (4 or 20). ### Task 5: Verified views and `from_bytes` (no public `unsafe`)

**Files:**
- Modify: `crates/zidl/src/lib.rs`, `crates/zidl/src/read.rs`, `crates/zidl-schemas/src/lib.rs`, `crates/zidl-schemas/src/{bank,game,iot,stream}.rs`, `crates/zidl-schemas/src/evo/*.rs` (only what breaks), `crates/zidl-bench/src/zidl_impl.rs`
- Test: `crates/zidl-schemas/tests/verified.rs` (new)

**Decision (a deviation from the design's name):** a generic `Verified<T>` in the runtime does not work: methods with trusted access would have to be `impl`s on a foreign type (the orphan rule), and any public `FromTable` would allow building it without verifying. So each table gets a view `XVerified<'a>` with a private field, built only by `verified()`/`from_bytes()` of its own module. The only `unsafe` sits in the string accessors of those views (generated code), with `// SAFETY:` pointing to the `verify()` that built them.

**Interfaces:**
- Consumes: `envelope::{decode, schema_id}`, `VerifyCtx`.
- Produces (the pattern Plan 2 will generate):
  ```rust
  // zidl
  #![deny(unsafe_code)]                 // allow only in read::str_unchecked
  #[doc(hidden)] pub unsafe fn TableRef::str_unchecked(...)  // same body
  // zidl-schemas/src/lib.rs
  pub trait FromVerified<'a>: Sized { #[doc(hidden)] unsafe fn from_verified(t: TableRef<'a>) -> Self; }
  pub struct VListR<'a, T> { /* private */ }  // len, is_empty, get(i) -> Result<T, Error>, iter
  // per root type X (Transaction, Frame, Telemetry, Chunk):
  pub const SCHEMA_ID: u64 = zidl::envelope::schema_id("<namespace>.<X>"); // e.g. "bank.v1.Transaction"
  impl<'a> X<'a> {
      pub fn verified(buf: &'a [u8]) -> Result<XVerified<'a>, Error>;   // read + verify(VerifyCtx::new(len))
      pub fn from_bytes(buf: &'a [u8]) -> Result<XVerified<'a>, Error>; // decode → schema_id == SCHEMA_ID otherwise SchemaMismatch → verified(payload)
  }
  // per table T: TVerified<'a>(T<'a>) with a private field, impl FromVerified,
  //   impl Deref<Target = T<'a>> when T reaches no string;
  //   when it does (bank::Transaction, bank::Entry): its own accessors, strings via str_unchecked,
  //   table lists as VListR<'a, EntryVerified<'a>>, the other accessors delegate.
  ```
  Remove the public `memo_unchecked`/`note_unchecked`. `zidl-schemas/src/lib.rs`: `#![deny(unsafe_code)]`, `#[allow(unsafe_code)]` only on the views' string accessors and on `from_verified`.

**`schemas/conformance.zidl`** (the textual source; `model.rs` describes it by hand and Plan 2 compiles it):
```
namespace conformance.v1;
enum Color : u8 { Red = 0, Green = 1, Blue = 2 }
struct Point { x: i32, y: i32 }
table Leaf { n @0: u32; s @1: string?; }
union Choice { Leaf @1: Leaf }
table Root {
  a_u8 @0: u8;           a_i16 @1: i16?;        a_u32 @2: u32 = 7;
  a_i64 @3: i64?;        a_u128 @4: u128?;      a_i128 @5: i128?;
  a_f32 @6: f32?;        a_f64 @7: f64?;
  flag @8: bool?;        flag2 @9: bool;
  color @10: Color?;     point @11: Point?;
  name @12: string?;     blob @13: bytes?;
  nums @14: [u16]?;      points @15: [Point]?;  leaves @16: [Leaf]?;
  names @17: [string]?;  blobs @18: [bytes]?;
  child @19: Leaf?;      choice @20: Choice?;
  @21: reserved;         // was `old @21: u32?`
}
```
Plus `RootV2` = `Root` + `extra @22: u64?` (for the evolution vectors).

**Interfaces:**
- Produces:
  ```rust
  // model.rs
  pub enum Ty { U8, U16, U32, U64, U128, I8, I16, I32, I64, I128, F32, F64, Bool,
                Enum { base: Box<Ty> }, Struct(&'static StructDef), Str, Bytes,
                List(Box<Ty>), Table(&'static TableDef), Union(&'static UnionDef) }
  pub struct Field { pub id: u16, pub name: &'static str, pub ty: Ty, pub presence: Presence } // Presence::{Required, Optional, Default(Value), Reserved}
  pub struct TableDef { pub name: &'static str, pub fields: Vec<Field> }   // in ID order
  pub fn conformance_root() -> &'static TableDef; pub fn conformance_root_v2() -> &'static TableDef;
  // interp.rs
  #[derive(Debug, Clone, PartialEq, Serialize, Deserialize)] #[serde(untagged or tagged — the builder's decision, documented in the vectors' README)]
  pub enum Value { Bool(bool), UInt(u128), Int(i128), F32(f32), F64(f64), Str(String), Bytes(Vec<u8>),
                   List(Vec<Value>), Table(BTreeMap<String, Value>), Union { tag: u16, value: Box<Value> } }
  pub fn read(buf: &[u8], root: &TableDef) -> Result<Value, zidl::Error>;  // full read: required fields, defaults, UTF-8, VerifyCtx::new(len)

Floats in JSON by their bits (`"f32:0x3fc00000"`) for exactness; `u128`/`i128` as decimal strings — exact, documented in the README.

- valid: `minimal` (only required fields; `a_u32` comes out as 7 by default), `all_fields`, `zero_is_present` (every optional scalar = 0, present), `empty_lists`, `streaming_leaves` (`leaves` written by `tables_streaming`: backward offsets), `unknown_enum` (`color = 9`), `unknown_union_tag` (tag 5 pointing to a `Leaf`), `v2_read_by_v1` (written with `RootV2`, read with `Root`: `extra` ignored), `v1_read_by_v2` (`extra` absent), `reserved_ignored` (bytes with slot 21 filled by an old writer: read without error and without the field), `enveloped_all_fields`.
- invalid (bytes built by hand from `minimal`): `truncated_slot` → `Truncated`; `bad_offset` → `BadOffset`; `string_len_oob` → `OutOfBounds`; `bad_utf8` → `InvalidUtf8`; `missing_required` → `Missing`; `self_cycle` (`child` pointing to the root itself) → `DepthExceeded`; `budget_amplification` (a list of 1000 `Leaf`s all pointing to the same large string) → `BudgetExceeded`; envelope: `env_bad_magic`, `env_bad_version` → `UnsupportedVersion`, `env_bad_header`, `env_cut_header` / `env_cut_payload` / `env_cut_crc` → `Incomplete`, `env_bitflip_payload` / `env_bitflip_crc` → `ChecksumMismatch`, `env_wrong_schema` → `SchemaMismatch`.

### Task 8: Normative v1 spec
